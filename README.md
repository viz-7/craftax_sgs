# SGS

Original <a href="https://arxiv.org/abs/2610.12465">paper</a> focuses on robotic envs that are not
very dynamic. This work adapts the core idea to a traditional RL problem on an env which is more
dynamic than locomotion and manipulation.

Read about it here: https://viz-7.github.io/articles/craftax_sgs.html

uv sync
